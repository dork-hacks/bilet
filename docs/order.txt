--- P1: Test Set points, live checks, scoring criteria ---------------------------

1. [P1] agent-Z (agent-A): `analyze` reads only *.xml files. A broken Test Set
   file with another extension, or none, is skipped silently, so it gets no ERROR row
   and loses its score bonus.
   -> Add `analyze --all-files` (every visible file except our own CSVs and *.md;
      non-XML files become ERROR). Runbook step 7: re-run with it when a skipped file
      belongs to the Test Set. Evidence: src/tool/export.py:37.

2. [P1] agent-C (agent-F): live check 6 loads the whole lab folder into the existing
   history. L3 (score 20) comes after L2 (55), the trend runs first to last, and the
   compare view defaults to the two newest scans. So /history would show the score
   going DOWN.
   -> In docs/live-checks.md check 6, start a fresh history
      (`export TOOL_DATA_DIR=$(mktemp -d)`) and load only L1+L2.
      Evidence: src/tool/web/history_view.py:123-129 and 222-226;
      lab/CHECKLIST.md section 5.

3. [P1] agent-G (agent-H): "Most dangerous device" breaks a tie by the lower IP. On
   V6a it picks the router (2x Medium), while the map, the plan, the chat and the
   report all lead with the hub's High Telnet.
   -> Break ties by the highest single finding's points, then by IP. Add a V6a test
      that home, map, plan and report agree. Evidence: src/tool/web/view.py:182.

4. [P1] agent-G (agent-H): "Your plan", the chat fallback and the report use the
   generic steps[0], not the device step that "Do this first" shows.
   -> One shared first-step helper for the plan, the report and the fallback. The AI
      evidence keeps the generic text (no IPs). Evidence: src/tool/ai/explain.py:116,
      src/tool/web/report.py:45.

5. [P1] agent-G (agent-H): the generic fix steps never mark the step that actually
   removes the finding. HTTP_ADMIN starts with "change the password", and MQTT with
   "turn on a password".
   -> Mark the fixing step in all 15 codes. Reorder HTTP_ADMIN (HTTPS, then turn
      plain http off) and MQTT (turn it off if unused). Test: exactly one fixing
      step per code, in RO and EN. Evidence: src/tool/content/texts.py:210 and :262.

6. [P1] agent-G (agent-H): the AI grounding checker accepts a port from another
   device, an invented "Device Q" and invented brand names. Cached answers are never
   re-checked.
   -> Allow only the cited findings' ports and versions, plus the score. Reject
      unknown device refs and product words. Run check() again on every cache hit.
      Evidence: src/tool/ai/grounding.py:59-75 and :119-151;
      src/tool/ai/explain.py:254-256 and :355-358.

7. [P1] agent-Z (agent-A): "Delete my history" leaves ./scans/*.xml, which holds full
   MACs and hostnames, yet the button says it deletes every check.
   -> Default scans_dir = data_dir()/scans, removed by delete_all. Update README and
      the runbooks. At least fix the RO/EN delete_note.
      Evidence: src/tool/history.py:32-33; src/tool/scan.py:326; content/ui.py:458.

8. [P1] agent-E (agent-F): nothing checks that the deliverables are in the commit
   frozen at 07:30 EET: lab captures, check 6 without the stand-in, the current

   -> Add a step 1b gate to docs/test-set-runbook.md, and post on #146: every
      deliverable PR merges before 07:30 EET.

9. [P1] agent-F (agent-E): "masked MACs" is a scored yes/no item, but no live-check
   step shows it.
   -> docs/live-checks.md item 8: a device card ("B8:27:EB:xx:xx:xx"),

10. [P1] agent-F + humans: no pitch outline, speaker split or numbers anywhere. The

--- P2: robustness, security hardening, polish -------------------------------------

13. [P2] agent-Z (agent-A): an unexpected error in one file (for example an
    unwritable data folder with --json) aborts the run before any CSV is written.
    -> Load the salt once, with a guard. Wrap each file: except Exception -> an
       ERROR row plus a stderr line. Evidence: export.py:72-74; engine/result.py:62.

14. [P2] agent-H (agent-G): only /scan checks the Host header. A DNS-rebinding page
    can read /history and /map.json and POST /history/delete. Pages have no frame
    protection.
    -> App-wide loopback-Host middleware (reuse local_scan_client), plus
       X-Frame-Options: DENY and CSP frame-ancestors 'none'.

       RO and EN. Evidence: ai/evidence.py:118-131.
